This method compares two images to find and highlight any differences. It is ideal for quality control where a known good reference image exists. The AI analyzes subtle variations to pinpoint defects.

Detection Parameters

This parameter sets the minimum similarity score required for two pixels to be considered identical. A lower threshold (e.g., 0.8) is less strict and will tolerate more subtle differences, while a higher threshold (e.g., 0.95) is more sensitive and will flag minor variations as defects. Adjusting this value impacts the number of detected defects.
